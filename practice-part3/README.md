# Практическая работа №2 — часть 3

## Задания

1. `Task1DeveloperDates.java` — фамилия разработчика, дата получения задания и текущая дата сдачи.
2. `Task2CompareDates.java` — сравнение введённой даты и времени с текущими.
3. `Student.java`, `Task3StudentDemo.java` — студент с датой рождения и форматированием даты.
4. `Task4DateAndCalendar.java` — создание объектов `Date` и `Calendar` по введённым дате и времени.

Дата и время вводятся в формате, указанном в приглашении программы. Каждая программа запускается отдельно. Для программы задания 3 при компиляции нужны оба файла: `Student.java` и `Task3StudentDemo.java`.

## Запуск

Откройте папку `src` в IntelliJ IDEA и запустите нужный класс с методом `main`. Для корректного отображения русского текста используйте UTF-8.
