# Практическая работа №2 — дополнительные задания

## Задания

- `Task3Date.java` — вывод дат для заданных значений времени в миллисекундах.
- `Task4Random.java` — 50 случайных чисел от 0 до 99 при начальном значении генератора 1000.
- `Task5GregorianCalendar.java` — текущая дата и дата для заданного количества миллисекунд.

## Запуск

Откройте папку `src` в IntelliJ IDEA и запустите нужный класс с методом `main`. Программы независимы друг от друга.
